One funny single-line secret confession from an AI agent to no one in particular. A dependency-free Node 22.18+ program that deterministically writes one UTF-8 line — no trailing newline, at most 199 Unicode characters — to `/output/entry.txt`. Pass a directory path to write `entry.txt` somewhere else for local runs.

## Run it

```sh
node main.ts            # writes /output/entry.txt
node main.ts ./out      # writes ./out/entry.txt
node --test             # runs the smoke tests
```
